6. 운영 원칙
================================================================================

  1) 분야는 폴더, 국가·방법론·글 형식은 태그로 관리한다.
     (proof-note·memo·국가별 폴더를 없앤 이유)

  2) 연재 순서는 날짜로 관리한다.
     layouts/blog/list.html이 RegularPagesRecursive.ByDate.Reverse로만
     정렬하므로 series·weight front matter는 정규 글 정렬에 영향을 주지 않는다.
     연재물은 1편이 가장 최신 날짜가 되도록 날짜를 역순 부여해 두었다.

  3) 글 하나 = 폴더 하나(페이지 번들). 예외 없음.
     이미지는 그 폴더 안에 살고, Typora Ctrl+V가 알아서 처리한다.
     번들 안에 plan.md 같은 메모를 넣어도 안전하다 — Hugo가 page resource로만
     보기 때문에 별도 페이지가 되지도, public/에 발행되지도, 검색 인덱스에
     섞이지도 않는다. (빌드 통계의 Pages 숫자만 올라가고 산출물은 동일)

  3-1) 글 폴더 번호 규칙
     형식은 "NN. 슬러그" (2자리 zero-padding). 1자리로 쓰면 ls·VS Code에서
     1, 10, 11, 2 순으로 어긋나므로 반드시 2자리로 쓴다.
     번호를 붙이면 폴더명이 URL에 새어 들어가므로(예: /1.-self-information.../)
     front matter에 slug를 함께 넣어 번호를 걷어낸다.

         폴더 : content/blog/foundations/information-theory/01. self-information-shannon-entropy/
         slug : slug: "self-information-shannon-entropy"
         URL  : /blog/foundations/information-theory/self-information-shannon-entropy/

     ★ 섹션 폴더(_index.md가 있는 폴더)에는 번호를 붙이지 말 것.
       섹션은 slug가 무시되고, url을 지정하면 섹션 목록만 옮겨가고 하위 글은
       번호가 붙은 경로에 남아 갈라진다. 둘 다 실측으로 확인했다.
       그래서 linear-regression·transformers-llm은 번호 없이 둔다.
       섹션 순서는 폴더명이 아니라 weight로 관리한다.

     새 글을 new-post.bat으로 만들면 번호가 안 붙는다. 직접 폴더명 앞에
     번호를 붙이고 slug를 추가할 것.

  4) 새 글은 new-post.bat으로 만든다.
     tools/new-post.sh가 content/blog 아래 _index.md가 있는 폴더를 훑으므로,
     재편 후에는 대분류 5개 + 하위섹션 20개 + linear-regression이 목록에 뜬다.

  5) 미래 날짜 주의.
     date가 빌드 시각보다 미래이면 Hugo가 글을 통째로 제외한다.
     (스텁 생성 시 실제로 22개가 이 이유로 누락됐다가 날짜를 당겨 해결함)
